08 — Tóm tắt

Tổng kết & Điểm chính

Điểm chính kiến trúc
🏛️ 5 Nhóm chức năng — 5 Microservices
Core · Document · Classification · Conversation · Analytics — Mỗi nhóm thuộc 1 microservice riêng biệt, tách biệt schema DB.
📦 RAG Pipeline hoàn chỉnh
DOCUMENT → DOCUMENT_VERSION (bất biến) → CHUNK (vector embedding) → Tìm kiếm ngữ nghĩa → AI trả lời → MESSAGE
🔐 Phân quyền nhiều lớp
accessLevel (public/dept/restricted) + ACCESS_RULE (role/dept/user) + CHUNK.allowedRoles + CHUNK.allowedDepartments
🐰 RabbitMQ — Event-Driven
User.status.changed · Document.uploaded · Unanswered.question — Cross-service communication giữa 5 microservices.
