07 — Tổng hợp quan hệ

Ma trận 16 Quan hệ ERD

Quan hệ Thực thể A Card A Thực thể B Card B Mô tả
BELONGS_TO USER (1,N) DEPARTMENT (1,1) User bắt buộc thuộc 1 Dept. Mỗi Dept chứa nhiều User.
HAS_CHILD (Dept) DEPARTMENT (0,N) DEPARTMENT (0,1) Cây phân cấp tổ chức. Dept con có thể có Dept cha.
OWNS USER (0,N) CONVERSATION (1,1) User sở hữu nhiều Conversation. Mỗi Conversation chỉ 1 User.
CONTAINS CONVERSATION (1,1) MESSAGE (1,N) Conversation bắt buộc chứa ít nhất 1 Message.
HAS MESSAGE (0,1) FEEDBACK (0,N) Message có thể có 0-N Feedback (like/dislike).
GENERATES MESSAGE (0,N) UNANSWERED_QUESTION (1,1) Message sinh ra câu hỏi chưa trả lời khi AI không tìm được nguồn.
UPLOADS USER (0,N) DOCUMENT (0,1) User upload nhiều Document. Mỗi Document có 1 người upload (ADMIN).
HAS_VERSION DOCUMENT (1,1) DOC_VERSION (1,N) Document bắt buộc có ít nhất 1 phiên bản. Phiên bản bất biến.
IS_SPLIT_INTO DOCUMENT (1,1) CHUNK (1,N) Document chia thành nhiều Chunk phục vụ tìm kiếm ngữ nghĩa (RAG).
CLASSIFIED_INTO DOCUMENT (0,N) CATEGORY (0,N) Document phân loại đa giá trị vào nhiều Category.
HAS_CHILD (Cat) CATEGORY (0,N) CATEGORY (0,1) Category có thể chứa Category con. Cấu trúc cây phân loại.
TAGGED_WITH DOCUMENT (0,N) TAG (0,N) Document gắn nhiều Tag. Tag là danh sách phẳng không phân cấp.
GOVERNS DOCUMENT (1,1) ACCESS_RULE (0,N) Document có quyền truy cập mặc định + nhiều Access_Rule bổ sung.
BELONGS_TO_DEPT DOCUMENT (0,N) DEPARTMENT (0,1) Document thuộc Dept sở hữu. Phân biệt với USER.BELONGS_TO.
PERFORMED_BY USER (1,N) AUDIT_LOG (1,1) Mọi thao tác quan trọng (login, upload, xóa...) đều được ghi nhận.
REQUESTS USER (0,N) REPORT_EXPORT (1,1) User yêu cầu xuất báo cáo. Xử lý async, file lưu trên MinIO/S3.
08 — Tóm tắt

Tổng kết & Điểm chính

Điểm chính
🏛️ 5 Nhóm chức năng rõ ràng
Core · Document · Classification · Conversation · Analytics — Mỗi nhóm thuộc 1 microservice riêng biệt, tách biệt schema DB.
📦 RAG Pipeline hoàn chỉnh
DOCUMENT → DOCUMENT_VERSION (bất biến) → CHUNK (vector) → Tìm kiếm ngữ nghĩa → AI trả lời → MESSAGE
🔐 Phân quyền nhiều lớp
accessLevel (public/dept/restricted) + ACCESS_RULE (role/dept/user) + CHUNK.allowedRoles + CHUNK.allowedDepartments
🐰 RabbitMQ — Event-Driven
User.status.changed · Document.uploaded · Unanswered.question — Cross-service communication.
