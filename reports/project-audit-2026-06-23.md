## [CRITICAL]

- **Fresh installations cannot initialize PostgreSQL.** `knowledge.document_audit_logs` is created twice at `infrastructure/init-db/003_knowledge.sql:196` and `infrastructure/init-db/003_knowledge.sql:278`; the verified clean container exited before seeds or later schemas ran.

- **Live-looking credentials are committed.** `docker-compose.yml:183` hardcodes the administrator password and `docker-compose.yml:188-189` contains a concrete SMTP account/app password; revoke the mail credential and rotate every exposed secret immediately.

- **Known internal key enables privilege escalation.** User/knowledge filters accept the default key and grant ADMIN at `services/user-service/src/main/java/com/poliwise/user/security/JwtAuthenticationFilter.java:40-55` and `services/knowledge-service/src/main/java/com/poliwise/knowledge/security/JwtAuthenticationFilter.java:40-55`, while the gateway forwards arbitrary client headers at `services/api-gateway/src/proxy/proxy.service.ts:362-379`.

- **Expired access tokens remain valid.** Expired claims are deliberately returned at `services/auth-service/src/main/java/com/poliwise/auth/service/JwtTokenProvider.java:74-79`, `services/user-service/src/main/java/com/poliwise/user/security/JwtAuthenticationFilter.java:105-106`, `services/knowledge-service/src/main/java/com/poliwise/knowledge/security/JwtAuthenticationFilter.java:133-134`, and `services/metadata-service/src/main/java/com/poliwise/metadata/security/JwtAuthenticationFilter.java:90-91`.

- **AI-QA trusts spoofable identity headers.** Any direct caller can claim arbitrary user/ADMIN identity at `services/ai-qa-service/src/api/dependencies/__init__.py:18-32`, and the service is publicly mapped at `docker-compose.yml:527-528`.

- **OnlyOffice callback supports authenticated SSRF and memory exhaustion.** An unchecked callback URL flows from `services/knowledge-service/src/main/java/com/poliwise/knowledge/controller/OnlyOfficeController.java:216-225` into unrestricted `HttpURLConnection` plus `readAllBytes()` at `services/knowledge-service/src/main/java/com/poliwise/knowledge/service/OnlyOfficeService.java:590-650`; the shared secret also has a public default at `docker-compose.yml:109`.

## [HIGH]

- **Feedback data is effectively public when accessed directly.** Security permits every request at `services/feedback-service/src/main/java/com/poliwise/feedback/config/SecurityConfig.java:43-47`, exposing audit and analytics endpoints such as `AuditController.java:25-33` through host port `docker-compose.yml:380-381`.

- **OnlyOffice callback identity is not bound to the request.** Signed claims are parsed at `OnlyOfficeCallbackFilter.java:63-81`, but the controller discards that principal and rebuilds one from path/body values at `OnlyOfficeController.java:222-225`.

- **Document upload has conflicting interfaces.** The frontend hardcodes direct `localhost:8083` access at `frontend/web/lib/api.ts:57-60,896-910`; the gateway exposes `/documents/upload` at `proxy.controller.ts:266-276`, while the backend only accepts POST `/documents` at `DocumentController.java:30-40`.

- **Unanswered-question administration is a dead-end.** The UI calls nonexistent GET/PUT AI routes at `frontend/web/lib/api.ts:1326-1339`; AI-QA implements only POST marking at `services/ai-qa-service/src/api/routes/unanswered.py:35`, while feedback exposes only GET at `DashboardController.java:33-36`.

- **Report generation is neither asynchronous nor persisted.** Self-invocation bypasses `@Async` at `ReportExportService.java:80-90,113-116`, then generated bytes are discarded while a fictitious `fileKey` is stored at `ReportExportService.java:126-130`.

- **Existing databases receive no migrations.** Compose only mounts PostgreSQL first-start initialization at `docker-compose.yml:11-13`, while `infrastructure/init-db/migrations/003_onlyoffice_document_locks.sql:7-33` has no Flyway/Liquibase/upgrade runner.

- **Stored HTML is rendered without sanitization.** DOCX content is converted and injected at `frontend/web/components/documents/PreviewModal.tsx:258-265,325-333` and `frontend/web/components/onlyoffice/ConflictResolver.tsx:101-111,278-282`.

- **Production dependencies contain numerous current high-severity advisories.** Vulnerable resolutions include Next at `frontend/web/pnpm-lock.yaml:2192`, gateway Axios at `services/api-gateway/pnpm-lock.yaml:1362`, Multer at `:2580`, and `path-to-regexp` at `:2737`.

- **The ingestion image is replaced by workstation source at runtime.** `docker-compose.yml:434-436` bind-mounts `services/ingestion-service/src` over the built image, invalidating build reproducibility.

- **Ordinary users can trigger document reprocessing.** Backend authorization is commented out at `DocumentController.java:329-333`, while the gateway wildcard explicitly permits USER at `proxy.controller.ts:370-379`.

- **Distributed rate limiting is nonfunctional.** Gateway dynamically requires an undeclared `redis` package at `rate-limit.interceptor.ts:49-78`, and its Redis limit exception is caught as an operational failure at `rate-limit.interceptor.ts:136-147`.

- **The documented frontend API URL produces a broken build.** `.env.example:42` specifies port 3000, which overrides the correct Compose default at `docker-compose.yml:621-627`.

## [MEDIUM]

- **Docker builds do not validate JVM tests.** All JVM Dockerfiles use `-DskipTests`, e.g. `services/auth-service/Dockerfile:15-17`, while their `.dockerignore:11` excludes test sources entirely.

- **Frontend production image is oversized.** `frontend/web/Dockerfile:23-26` copies the complete build-time `node_modules`, producing a 378 MB image instead of using Next standalone output.

- **Frontend cache reproducibility is weak.** `frontend/web/Dockerfile:12` installs without `--frozen-lockfile`, and `frontend/web/.dockerignore:1-12` does not exclude `.next`, causing avoidable context transfer/cache invalidation.

- **Configured JVM memory settings are ignored.** Dockerfiles declare `JAVA_OPTS` but execute `java` directly, e.g. `services/knowledge-service/Dockerfile:29,39`; Java does not automatically consume `JAVA_OPTS`.

- **Password-change errors trigger a second, invalid request.** Any legitimate failure is swallowed and retried against nonexistent `PUT /api/v1/auth/password` at `frontend/web/app/profile/change-password/page.tsx:73-98`.

- **Historical reports silently omit records.** Feedback reports load only the newest 200/500 records before applying date filters at `ReportExportService.java:306-310,368-373`.

- **CSV exports allow spreadsheet formula injection.** User-controlled values are escaped only for delimiters at `ReportExportService.java:614-619`, without neutralizing leading `=`, `+`, `-`, or `@`.

- **Core UI/gateway modules have no automated tests.** Test scripts exist at `services/api-gateway/package.json:16-20`, but gateway, frontend, knowledge, metadata, feedback, and user services contain no test files.

## [LOW]

- **Python dependency builds are not reproducible.** Dependencies use unconstrained lower bounds without lock files at `services/ai-qa-service/pyproject.toml:7-24` and `services/ingestion-service/pyproject.toml:7-48`.

- **Database documentation references a deleted entrypoint.** `infrastructure/init-db/README.md:10-12` names `init.sql`, although the current bootstrap relies on directly mounted numbered scripts.
